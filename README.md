# ace2s-shield-plus-paper

This repository contains the code for performing the experiments described in 
the manuscript titled "Disentangling the effects of sea surface temperature and
CO<sub>2</sub> in global machine learned weather-climate emulators," submitted
to the Journal of Geophysical Research: Machine Learning and Computation. 
A pre-print can be found [here](https://arxiv.org/abs/2606.07928v1).

- `ACE-experiments` includes the configuration and code for submitting training
  and inference jobs with ACE.
- `SHiELD-simulations` includes the configuration and code for running and
  processing the new SHiELD simulations completed for this study.
- `manuscript` includes the code for producing the figures shown in the
  manuscript.
